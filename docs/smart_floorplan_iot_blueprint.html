محرر الصالة التفاعلي الحي وربط إضاءة الطاولات بالـ IoT (ESP32)

توثيق هندسي وتنفيذي دقيق لميزة تخطيط صالات المطاعم ثنائية الأبعاد (2D Interactive Floor Plan Canvas)، ومزامنة حالات الطاولات اللحظية عبر Laravel Reverb، والربط بالعتاد المادي الذكي لشريحة ESP32 للتحكم بالإضاءة المحيطية المتناغمة مع نظام حجز طاولات زبائن VIP.
إصدار الوثيقة: v1.0.0 (Production Blueprint)
تاريخ الإصدار: نوفمبر 2026
Target Architecture: Vue 3 + Laravel 12 + ESP32
Protocol: WebSockets / MQTT (WS2812B LEDs)

1 الرؤية الاستراتيجية والقيمة التنافسية

تنتقل منصة «تدلّل» بهذه الميزة من مجرد برنامج إدارة نقاط بيع وقوائم طعام رقمية (POS & Digital Menu) إلى منظومة ضيافة حية فاخرة (Luxury Smart Hospitality). تجمع الميزة بين ثلاثة أبعاد غير مسبوقة في السوق:

🗺️ محرر صالة تفاعلي

لوحة تحكم حية لمدير المطعم والكاشير لرسم مخطط الصالة وتوزيع الطاولات بأشكالها الواقعية، ومراقبة حالة كل طاولة ومبيعاتها لحظياً.

💎 حجز VIP مرئي للزبائن

صفحة فاخرة مخصصة لزبائن النخبة تتيح لهم استعراض صالة المطعم ثلاثية الأبعاد واختيار الطاولة المحببة وتأكيد الحجز المسبق قبل الحضور.

💡 تناغم الإضاءة المحيطية (IoT)

شريحة ESP32 مدمجة بكل طاولة تتحكم بحلقات إضاءة متوهجة تعكس حالة الطاولة على المنصة بريقاً ولوناً دون أي تدخل بشري.

3 تصميم العتاد والدوائر الإلكترونية (ESP32 & Circuit Specs)

تم تصميم وحدة الطاولة لتكون منخفضة التكلفة، فائقة الاستقرار، وتعمل بجهد 5V DC آمن تماماً (عبر شاحن طاولة مخفي أو بطارية ليثيوم قابلة للشحن).

المكوّن (Component) المواصفات التقنية (Specs) الوظيفة في طاولة المطعم
ESP32 NodeMCU / WROOM Dual-Core 240MHz, 2.4GHz Wi-Fi, 4MB Flash معالجة إشارات الشبكة والاشتراك بقناة الطاولة والتحكم بالليدات.
WS2812B / SK6812 NeoPixel Ring حلقة قطرية 16/24 LEDs أو شريط معنون 60 LEDs/m توليد الإضاءة المحيطية المتوهجة أسفل حافة الطاولة أو في المنتصف.
Logic Level Shifter (74AHCT125) تحويل إشارة التحكم من 3.3V إلى 5.0V ضمان استقرار إشارة الداتا لليدات وتفادي أي وميض عشوائي (Flicker).
مكثف حماية (Capacitor) 1000uF / 6.3V - 16V Electrolytic تنعيم تيار التغذية وامتصاص صدمات التشغيل اللحظية لليدات.
مقاومة حماية خط الداتا 330Ω - 470Ω Resistor حماية منفذ GPIO في الـ ESP32 من الارتدادات.

مخطط التوصيل الكهربائي الصندوقي (Wiring Schematic)

+5V Power Supply ----------------+-----------------+---> (5V VCC of WS2812B Strip) | | [1000uF Cap] +---> (5V VIN of ESP32) | GND Power Supply ----------------+-----------------+---> (GND of WS2812B & ESP32) ESP32 GPIO 16 -----[330Ω Resistor]---------------------> (DIN Data-In of WS2812B)

4 مصفوفة حالات الطاولة والإضاءة المتناغمة

حالة الطاولة (State) كود اللون (HEX) نمط الإضاءة (Animation) دلالة الحالة للمطعم والزبون
فارغة وجاهزة (Available) #E2E8F0 دافئ خافت توهج هادئ جداً (Soft Low Glow 15%) الطاولة نظيفة ومتاحة لاستقبال الزبائن الجدد.
حجز VIP قادم (Reserved) #D4AF37 ذهبي ملكي نبض تنفسي بطيء (Breathe Pulse 1.5s) الطاولة محجوزة؛ يراها ضيف النخبة فور دخوله ويشعر بالفخامة.
مشغولة / جلسة طعام (Active) #10B981 زمردي أنيق إضاءة ثابتة دافئة (Steady Warm 40%) الزبائن يتناولون طعامهم، إضاءة مريحة لا تزعج العين.
طلب نداء أو فاتورة (Alert) #F43F5E ياقوتي متوهج نبض سريع لافت (Pulsing Flash 0.5s) تنبيه النادل المسؤول في تلك المنطقة لتلبية طلب الزبون فوراً.
قيد التنظيف والتعقيم (Turnover) #06B6D4 أزرق سماوي دوران خفيف (Rotating Halo) إشعار فريق التجهيز بأن الطاولة تحتاج تنظيف قبل جلوس زبون جديد.

5 كود شريحة الـ ESP32 Firmware (جاهز للتحميل المباشر)

كود احترافي بلغة C++ (Arduino/PlatformIO) يشتمل على إعادة الاتصال التلقائي بالشبكة، واستهلاك قنوات MQTT، وتنعيم انتقالات الألوان (Non-blocking Color Fade): 

/*
 * Tedallal Smart Table IoT Firmware (ESP32 + FastLED)
 * Features: Auto WiFi, MQTT Table Channel Subscription, Smooth Ambient Color Transitions
 */
#include <WiFi.h>
#include <PubSubClient.h>
#include <FastLED.h>
#include <ArduinoJson.h>

#define LED_PIN     16
#define NUM_LEDS    24
#define LED_TYPE    WS2812B
#define COLOR_ORDER GRB

const char* ssid        = "Tedallal_Restaurant_WiFi";
const char* password    = "Secure_Guest_Pass2026";
const char* mqtt_server = "mqtt.tedallal.com";
const char* table_topic = "tedallal/restaurants/1/tables/08/state";

CRGB leds[NUM_LEDS];
WiFiClient espClient;
PubSubClient client(espClient);

CRGB currentColor = CRGB::Black;
CRGB targetColor  = CRGB(212, 175, 55); // Gold default
String currentEffect = "breathe";

void callback(char* topic, byte* payload, unsigned int length) {
    StaticJsonDocument<256> doc;
    deserializeJson(doc, payload, length);
    
    const char* status = doc["status"]; // "available", "reserved", "active", "alert"
    const char* hex    = doc["color"];  // e.g. "#D4AF37"
    
    if (strcmp(status, "reserved") == 0) {
        targetColor = CRGB(212, 175, 55); currentEffect = "breathe";
    } else if (strcmp(status, "active") == 0) {
        targetColor = CRGB(16, 185, 129); currentEffect = "solid";
    } else if (strcmp(status, "alert") == 0) {
        targetColor = CRGB(244, 63, 94);  currentEffect = "pulse_fast";
    } else {
        targetColor = CRGB(100, 116, 139); currentEffect = "dim";
    }
}

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
    FastLED.setBrightness(80);
    WiFi.begin(ssid, password);
    while (WiFi.status() != WL_CONNECTED) { delay(500); }
    client.setServer(mqtt_server, 1883);
    client.setCallback(callback);
}

void loop() {
    if (!client.connected()) {
        if (client.connect("ESP32_Table_08")) { client.subscribe(table_topic); }
    }
    client.loop();
    
    // Smooth Luxury Breathing Effect
    if (currentEffect == "breathe") {
        float breath = (exp(sin(millis() / 2000.0 * PI)) - 0.36787944) * 108.0;
        FastLED.setBrightness((uint8_t)breath);
        fill_solid(leds, NUM_LEDS, targetColor);
    } else {
        FastLED.setBrightness(70);
        fill_solid(leds, NUM_LEDS, targetColor);
    }
    FastLED.show();
    delay(20);
}

6 بنية البيانات البرمجية (Database Schema & Models)

توسيع جدول الطاولات restaurant_tables ليدعم التموضع الهندسي والأبعاد والمناطق ومعرّف جهاز الـ IoT:

📂 توسعة جدول: restaurant_tables
  • pos_x: الإحداثي الأفقي على شبكة المخطط (integer / float)
  • pos_y: الإحداثي الرأسي على شبكة المخطط (integer / float)
  • rotation: زاوية الدوران بدرجات 0-360°
  • shape: شكل الطاولة (circle, rectangle, booth)
  • capacity: سعة المقاعد (2, 4, 6, 8, VIP-Lounge)
  • zone: المنطقة (main_hall, terrace, vip_lounge)
  • iot_device_id: المعرّف الفريد للـ ESP32 (MAC / Token)
📂 جدول الحجوزات: table_reservations
  • restaurant_id: معرّف المطعم
  • table_id: الطاولة المحجوزة في المخطط
  • guest_name & guest_phone: بيانات ضيف VIP
  • reservation_time: موعد الحضور المتوقع
  • guests_count: عدد الأفراد المرافقين
  • status: حالة الحجز (pending, confirmed, seated, cancelled)
  • deposit_amount: عربون الحجز إن وُجد

7 واجهة مخطط الصالة التفاعلي (Vue 3 Floor Plan Engine)

مكوّن Vue 3 فخم مستوحى من المخططات المعمارية الداكنة (Architectural CAD Blueprint)، يدعم وضعين متكاملين:

🖥️ وضع الإدارة والكاشير (Host & Admin)

• سحب وإفلات الطاولات (Drag & Drop) وحفظ الإحداثيات آنياً.
• تغيير سريع لحالة الطاولة بنقرة واحدة (تحرير، إشغال، تعليق).
• عرض مؤقت الجلسة الحالية وإجمالي الفاتورة المفتوحة فوق كل طاولة.
• إمكانية ربط كود الـ ESP32 من نافذة تعديل الطاولة.

📱 وضع حجز الـ VIP للزبائن (Public Flow)

• استعراض صالة المطعم بتصميم جذاب يحاكي الصالة الواقعية.
• تمييز الطاولات المحجوزة باللون الذهبي والمشغولة بالرمادي.
• النقر على طاولة متاحة لاختيار موعد الحضور وعدد الضيوف.
• تأكيد الحجز وإرسال إشعار فوري عبر الواتساب مع كود الحجز.

8 خطة التفعيل والجدول الزمني

المرحلة المهام التنفيذية المخرجات
المرحلة الأولى (الآن) توسيع قاعدة البيانات بملف هجرة، إضافة قفل الميزة (Feature Gate) في الباقات، وبناء مكوّن الصالة في لوحة الإدارة. محرر صالة شغال، قادر على حفظ إحداثيات ومناطق الطاولات.
المرحلة الثانية ربط الحالات اللحظية عبر Laravel Reverb وإظهار الطاولات النشطة والفواتير للكاشير والمضيف. مخطط حي يتغير لون طاولاته فور إرسال الطلبات.
المرحلة الثالثة بناء صفحة حجز زبائن VIP العامة وتوليد إشعارات الحجز المسبق. تجربة حجز بصرية متكاملة للهواتف وسطح المكتب.
المرحلة الرابعة نشر جسر الـ MQTT وتوريد وبرمجة وحدات الـ ESP32 لطاولات المطاعم. تناغم الإضاءة الفيزيائية المحيطية على أرض الواقع.
