# Formatting Rules for RTL Languages

عند كتابة نصوص عربية وإنجليزية في نفس السطر، يجب الالتزام بالقواعد التالية لتجنب التداخل العكسي للكلمات:
1. وضع الكلمات الإنجليزية (مثل أسماء المتغيرات، التقنيات، أو أسماء الملفات) بين علامات التنصيص البرمجية `backticks` دائماً.
2. استخدام فصل واضح بين اللغتين لمنع مشاكل العرض ثنائي الاتجاه (Bi-Directional display issues).
3. عند إنشاء ملفات `Markdown` أو عند كتابة رسائل عادية في الدردشة (Chat Responses) باللغة العربية، **يجب** إحاطة كامل محتوى الرسالة أو الملف بالوسم `<div dir="rtl">` في البداية، و `</div>` في النهاية، لضمان محاذاة النص وترتيبه بشكل سليم يمين-يسار.
